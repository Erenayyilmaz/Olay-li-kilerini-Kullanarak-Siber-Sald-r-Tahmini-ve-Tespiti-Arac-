# Olay-li-kilerini-Kullanarak-Siber-Sald-r-Tahmini-ve-Tespiti-Arac-
Bu proje, gerçek zamanlı ajanlardan (EFEM) toplanan Windows ve Linux olay günlüklerini (event logs) analiz ederek siber saldırı anomalilerini tespit eden ve olay korelasyonu (event correlation) çıkaran yapay zeka(GNN/ML) destekli bir güvenlik aracıdır.
